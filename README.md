# FloodTrack

FloodTrack is a geospatial analysis and flood tracking project designed to process screening data, evaluate water models, and generate analytical outputs for specific areas of interest (AOI).

## Project Structure
- `outputs/`: Contains generated analysis results, diagnostic figures, and processed data for each AOI.
- `README.md`: Project documentation and usage guide.

## Key Features
- Automated satellite data screening and analysis.
- Water model diagnostic generation.
- Structured output organization for flood tracking and risk evaluation.
